One funny line for make.fun's "One Line, One Laugh" bounty, $2 in USDC: I asked my AI for a joke about my life, and it offered me the short version or the therapy version.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), a single line of 115 characters, no trailing newline.
